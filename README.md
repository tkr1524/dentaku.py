四則演算電卓

1. 作品概要

Pythonの基礎学習を目的として、四則演算を繰り返し実行できる電卓プログラムを制作しました。

iPhoneのPythonista 3を使用して開発し、ユーザーが数字と演算子を入力することで計算結果を表示する仕組みを実装しました。

2. 使用技術

* 開発言語：Python 3
* 開発環境：Pythonista 3（iPhone）
* ソースコード：dentaku.py

3. 実装した機能

* 足し算・引き算・掛け算・割り算
* while文による繰り返し計算
* if・elif・elseによる条件分岐
* 0による除算を防ぐ処理
* ユーザー入力によるプログラムの終了

4. 工夫した点

・繰り返し計算への対応

while文を使用し、一度の起動で何度でも計算できるようにしました。

・割る数が0の場合の挙動

割り算の際に2つ目の数字が0だった場合、メッセージを表示するようにしました。

エラーの修正

開発中にインデントの不一致やコードの表記ミスによるエラーが発生しました。

コードの構造ルール等を見直し、修正しました。

5. 学んだこと

今回の制作を通じて、Pythonの変数、条件分岐、繰り返し処理、関数の基本的な使い方を学びました。

また、エラーメッセージを確認し、原因を特定して修正することの重要性を理解しました。

6. 実行方法

1. Python 3を実行できる環境を用意します。
2. dentaku.pyを開きます。
3. プログラムを実行します。
4. 表示に従って数字と演算方法を入力します。
